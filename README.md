# Распознавание болезней растений

Проект по распознаванию болезней растений с помощью нейросети.

## Установка

Установи нужные библиотеки:
pip install tensorflow matplotlib

## Запуск

1. Подготовь папки с фото:
   - `dataset/train/` — фото для обучения
   - `dataset/valid/` — фото для проверки

2. Запусти обучение:
python codeAi.py

3. После обучения модель будет в `model/plant_disease_model.h5`

4. Для распознавания на новом фото:
python detect.py путь_к_фото.jpg
